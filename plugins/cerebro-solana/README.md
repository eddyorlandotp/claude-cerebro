# cerebro-solana

Skills para construir sobre Solana con Claude Code: fundamentos, Jupiter (swaps y comisiones de integrador), Helius (RPC y tiempo real), envío rápido de transacciones, bot de copy trading, riesgo de memecoins, montos y decimales, billeteras sin custodia y backtesting de señales. Incluye el agente `auditor-transacciones`.

## Servidores MCP incluidos

Ambos son remotos, gratuitos, de solo lectura de documentación y no piden credenciales:

- `solana`: Solana Developer MCP, `https://mcp.solana.com/mcp`.
- `jupiter-docs`: documentación de Jupiter, `https://developers.jup.ag/docs/mcp`.

## Privacy

Las consultas a esos servidores las reciben sus operadores:

- Solana: https://solana.com/privacy-policy
- Jupiter: https://developers.jup.ag/docs/legal/privacy-policy
