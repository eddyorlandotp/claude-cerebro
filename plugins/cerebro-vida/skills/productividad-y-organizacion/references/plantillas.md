# Plantillas para productividad-y-organizacion

Si la bóveda ya tiene archivos con otro formato, adáptate al existente en lugar de imponer estos.

## Pendientes.md

```markdown
# Pendientes
Actualizado: AAAA-MM-DD

## Bandeja
- [ ] (todo lo nuevo cae aquí sin ordenar; se vacía en la revisión semanal)

## Hoy (máximo 3)
- [ ] Verbo + qué + con quién/dónde

## Esta semana
- [ ] [[Proyectos/<proyecto>/estado|<proyecto>]]: siguiente acción concreta
- [ ] …

## Con fecha
- [ ] Examen de [materia] (fecha: AAAA-MM-DD)
- [ ] Pagar tarjeta: pago para no generar intereses (fecha: AAAA-MM-DD)
- [ ] Renovar [dominio / e.firma / suscripción] (fecha: AAAA-MM-DD)

## Algún día
- [ ] …
```

## Proyectos/Inicio.md (columna de estado; el resto lo define memoria-obsidian)

```markdown
| Proyecto | Estado | Siguiente acción | Revisar el |
|---|---|---|---|
| [[Proyectos/<proyecto>/estado\|<proyecto>]] | Activo | … | — |
| [[Proyectos/<otro>/estado\|<otro>]] | Pausado | Al volver: … | AAAA-MM-DD |
| [[Proyectos/<viejo>/estado\|<viejo>]] | Archivado | — | — |
```

## Semanas/AAAA-Www.md

```markdown
# Semana AAAA-Www (lunes DD/MM – domingo DD/MM)

## Prioridad de la semana (1 frase)

## Bloques
| Día | Fijo (escuela/trabajo) | Bloque profundo | Bloque corto | Libre |
|---|---|---|---|---|
| Lun | 07:00–14:00 trabajo | 17:00–18:30 [proyecto]: [tarea] | 19:00–19:30 mensajes y pagos | — |
| … | | | | |

## Revisión (al cierre de la semana)
- Terminado:
- Se movió 2+ veces (¿partir o soltar?):
- Dinero por proyecto (entró / salió):
- Fechas próximas (14 días):
- Proyectos: sigue activo / pausar / reactivar:
- 3 tareas para el primer día de la siguiente semana:
```
