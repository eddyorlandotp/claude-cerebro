# local/

Carpeta aparte para lo que produce la IA que corre en la máquina del usuario (reportes y capturas). No forma parte de ningún plugin, así que no se instala ni gasta contexto.

- `telarana/capturas-nube/`: capturas del panel hechas en la nube con la sesión simulada.
- `telarana/REPORTE.md` y `telarana/capturas/`: los escribe Claude Code local al seguir `plugins/cerebro-panel/docs/PROMPT-LOCAL.md`.
